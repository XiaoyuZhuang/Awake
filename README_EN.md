# Awake

Awake is a lightweight Android reminder timer designed to work without a traditional app interface.

## Features

- Tap the app icon to add configurable countdown time
- Default: add 10 minutes
- Configurable countdown duration
- Configurable reminder interval after countdown finishes
- Persistent notification showing remaining time
- Temporary notification when time is added
- Notification-based settings access
- Chinese / English localization
- Light / dark theme support
- Vibration and sound controls
- Notification controls
- GitHub Release update checker

## Usage

1. Open Awake to add time.
2. Check the persistent notification for remaining time.
3. Enter settings from notification.

## Build

The project supports GitHub Actions Android builds.
