# Awake

轻量级 Android 倒计时提醒工具。[English README](README_EN.md)

[下载最新签名 APK](https://github.com/XiaoyuZhuang/Awake/releases/latest)

## 使用

1. 点击应用图标，默认增加 10 分钟倒计时，首次安装默认进入设置；选择“仅通过通知进入”后，启动时不显示应用窗口。
2. 每次增加时间显示短暂的“时间加 1”提示及当前倒计时；常驻通知显示剩余时间；点击通知进入设置，也可直接点击通知中的“增加时间”或“停止”。
3. 倒计时结束后默认每 10 秒提醒一次，直到增加时间或停止。
4. 首次启动请允许通知权限，否则通知入口无法显示。可以通过 Android 系统应用信息中的通知设置重新开启。

## 自定义设置

- 每次启动增加的时间：1–1440 分钟，默认 10 分钟。
- 到时提醒间隔：1–3600 秒，默认 10 秒。
- 声音、震动、到时通知分别开关。
- 设置入口：“仅通过通知进入”或“每次启动后进入设置”（新安装默认）。两种模式下，点击应用图标都会增加倒计时；点击通知进入设置不会增加时间。
- 中文／English，跟随系统／浅色／纯黑夜间主题。
- “立即增加倒计时”和“停止倒计时与提醒”。

## 更新与安装

点击“检查更新”先读取 GitHub 最新 Release 的版本信息。存在较新版本时，询问是否打开发布页；否则显示“已经是最新版本”。网络失败时提示重试。

Releases 中的 `Awake-release.apk` 是签名安装包。同一签名的 Release 版本可直接覆盖安装并保留设置。Debug 与 Release 签名不同，不能互相覆盖安装。

## 构建与发布

main 分支提交及手动运行 Actions 都会执行 Debug 编译与 Lint 检查。配置以下 Repository Secrets 后，工作流还会构建签名 Release APK 并自动发布：

- `KEYSTORE_BASE64`
- `KEY_ALIAS`
- `KEYSTORE_PASSWORD`
- `KEY_PASSWORD`

版本号位于 `app/build.gradle.kts` 和 `version.json`，发布新版本时需要同步更新，并递增 `versionCode`。签名密钥不得提交至仓库。

## 后台与隐私

前台服务通过通知运行，倒计时截止时间保存在本地。部分手机的省电策略可能延迟后台提醒，可以在系统设置中允许后台运行。

无需账号，不收集个人信息。设置保存在本机；仅检查更新时访问 GitHub。
